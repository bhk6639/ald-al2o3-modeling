# Phase 3: 온도 편차에 따른 두께 산포와 관리 스펙

날짜: 2026-08-23
코드: `src/phase3_uniformity.py`
그래프: `fig/phase3_sensitivity_spec.png`, `fig/phase3_linearity_distribution.png`

## 1. 목표

`01_모델설계.md` 5절을 양산 관리 관점으로 확장했다.

1. 선형 근사 `산포 = S x ΔT`가 어디까지 유효한가
2. 웨이퍼 내 온도 분포가 두께 분포로 어떻게 전파되는가
3. 목표 두께 산포에서 필요한 온도 균일도는 얼마인가
4. 같은 온도 편차에서 ALD와 LPCVD poly-Si의 차이는 얼마인가

## 2. 계산 비용과 스플라인

Phase 2 모델의 GPC 한 점이 약 0.9 s다(12 사이클 x 2 반쪽 ODE). 분포 전파는 2001점, 스펙 역산은 이분법 60회 x 401점을 쓴다. 직접 호출하면 수십 분이 걸려 실제로 10분 타임아웃에 걸렸다.

GPC(T)가 매끄러우므로 120 ~ 360도 25점에서 한 번 계산해 3차 스플라인으로 보간했다. 구축에 23 s.

정확도를 격자에 없는 5개 점에서 원 모델과 직접 대조했다.

| 항목 | 최대 상대오차 |
|---|---|
| GPC 값 | 1.68e-6 |
| S(T) (미분값이라 더 민감) | 1.46e-4 |

통과. 이후 모든 계산은 스플라인으로 한다.

## 4. 목표 1: 선형 근사의 유효 범위

`fig/phase3_linearity_distribution.png` 좌측.

| ΔT [K] | ALD 모델 오차 | LPCVD 오차 |
|---|---|---|
| 1 | 0.00 % | 1.17 % |
| 5 | 0.00 % | 5.75 % |
| 10 | 0.00 % | 11.24 % |
| 20 | 0.00 % | 21.41 % |
| 50 | 0.00 % | 46.10 % |

**정직하게 짚을 것**: ALD 쪽 오차가 정확히 0으로 나오는 것은 부분적으로 자명하다. 모델의 sigma_OH0(T)가 선형 실측 관계이고 GPC가 거기에 선형으로 붙으므로, GPC(T)의 선형성은 **입력에서 물려받은 성질**이지 독립적인 예측이 아니다.

그래도 의미가 있는 이유는 문헌 GPC(T)도 선형 피팅이기 때문이다([P05] Fig.19, 8개 그룹 데이터). 선형성 자체가 실측으로 뒷받침된다.

**대비가 핵심이다.** LPCVD는 Arrhenius라 ΔT가 커지면 선형 예측에서 빠르게 벗어나고 부호에 따라 비대칭이다(+50 K에서 46 % 어긋남). ALD의 장점은 민감도가 작다는 것만이 아니라 **예측 가능하다**는 것이다. 온도 편차가 커져도 산포를 선형으로 외삽할 수 있다.

## 7. 공정능력지수와 예산 배분

Cp = 규격 반폭 / (3 x 두께 1 시그마). Cp >= 1.33이 통상 목표.

| 규격 | sigma_T [K] | 두께 1 시그마 [%] | Cp | 판정 |
|---|---|---|---|---|
| +/-1 % | 1.0 | 0.176 | 1.9 | 통과 |
| +/-1 % | 2.0 | 0.352 | 0.9 | 미달 |
| +/-1 % | 5.0 | 0.879 | 0.4 | 미달 |
| +/-2 % | 1.0 | 0.176 | 3.8 | 통과 |
| +/-2 % | 2.0 | 0.352 | 1.9 | 통과 |
| +/-2 % | 5.0 | 0.879 | 0.8 | 미달 |

Cp = 1.33을 만족하는 최대 온도 균일도 (문헌 기준)

    규격 +/-1 %   ->   sigma_T <= 1.43 K
    규격 +/-2 %   ->   sigma_T <= 2.85 K

### 7.1 처음 예상이 틀렸다

이 Phase를 시작할 때는 "ALD는 온도에 둔감하니 두께 산포의 병목은 온도가 아니라 dose일 것"이라고 적어뒀다. **계산 결과가 그것을 반박했다.**

규격을 3 시그마로 잡고 온도와 dose가 독립이라 보고 제곱합으로 나누면

| 규격 | 허용 1 시그마 | sigma_T | 온도가 쓰는 몫 | 온도 비중 | 남는 예산 |
|---|---|---|---|---|---|
| +/-1 % | 0.333 % | 1.0 K | 0.176 % | 52.8 % | 0.283 % |
| +/-1 % | 0.333 % | 2.0 K | 0.352 % | 105.5 % | 초과 |
| +/-2 % | 0.667 % | 1.0 K | 0.176 % | 26.4 % | 0.643 % |
| +/-2 % | 0.667 % | 2.0 K | 0.352 % | 52.8 % | 0.567 % |

**규격 +/-1 %에서는 sigma_T = 2 K만 되어도 온도 하나가 예산을 다 쓴다.** ALD가 CVD보다 19배 둔감한 것은 사실이지만, 규격도 그만큼 빡빡하다. 온도는 무시할 수 있는 항이 아니다.

코드에서 이 해석을 하드코딩했다가 표와 모순되는 것을 발견하고 계산에서 뽑도록 고쳤다. 결론을 미리 적어두면 안 된다는 사례로 남긴다.

## 8. Phase 5로 넘기는 입력

    규격 +/-2 %, sigma_T = 2 K 기준
    dose 변동이 쓸 수 있는 두께 1 시그마 예산 = 0.567 %

Phase 5에서 이 값으로 필요한 포화 마진을 역산한다.

## 9. 한계

**9.1 온도 편차 값은 문헌이 아니라 가정이다**

+/-1, 2, 5 K 등은 운전 시나리오로 넣은 값이다. 실제 장비의 웨이퍼 내 온도 균일도 스펙을 확보하지 못했다. 표는 시나리오별로 읽어야 하고, 실제 값이 나오면 그 값으로 다시 채우면 된다.

**9.2 모델 민감도가 문헌보다 22 % 낮다**

Phase 1의 sMe_max 선택에서 이월된 사항이다. 관리 스펙은 보수적인 문헌 기준을 쓰는 것으로 대응했다.

**9.3 온도 외의 산포원을 다루지 않았다**

압력 변동, 퍼지 부족, 하지막 차이, 웨이퍼 간 편차는 이 Phase 밖이다. 제곱합 분해에서 "남는 예산"으로만 표현했다.

**9.4 정상상태만 본다**

인큐베이션 구간의 GPC 차이는 Phase 4 주제다. 얇은 막(수 nm)에서는 이쪽이 지배적일 수 있다.
