# 부록 A: 응축 모델을 Ea_dehyd 기반으로 바꿔보고 되돌린 기록

날짜: 2026-08-23
코드: `src/phase2_temperature.py`의 `CONDENSATION_MODEL` 스위치

## A.1 왜 바꾸려 했나

Phase 2 8.1절과 Phase 5 3절에 적어둔 한계다. 기존 모델(`flux_coupled`)은 응축 속도를 물 플럭스에 묶어놨다.

    R_net = beta_H2O x Gamma_H2O x r_diss x (1 - s_OH / sigma_OH0)

물을 끊으면 이 항이 0이 되므로 과잉 OH를 되돌릴 수 없다. 실제 탈수산화는 물이 없어도 진행된다(퍼지 중에도). 그 결과 H2O 포화 곡선이 중간 dose에서 점근값을 0.77 % 초과하는 비단조 봉우리를 만들었다.

## A.2 무엇으로 바꿨나

물이 필요한 과정과 아닌 과정을 분리했다.

    리간드교환  Me* + H2O -> OH* + CH4         물 필요
    해리        H2O + Al-O-Al -> 2 Al-OH       물 필요
    응축        2 Al-OH -> Al-O-Al + H2O       물 불필요. OH에 2차

[Z00]이 실험으로 확정한 반응차수 n = 2.00을 따라 응축을 2차로 뒀다. 해리와 응축의 균형이 sigma_OH0(T)를 만들도록 k_d = k_c sigma_OH0^2로 두면

    H2O 단계   dOH/dt = R_le + k_c (sigma_OH0^2 - s_OH^2)
    퍼지 단계  dOH/dt = -k_c s_OH^2

응축 속도상수는 [02 #7]의 Ea_dehyd로 온도 의존을 주고, 전인자는 문헌에 없으므로 200도에서의 선형화 완화시간 tau_c로 파라미터화했다.

사이클도 `TMA -> 퍼지 -> H2O -> 퍼지`로 확장했다.

## A.3 결과: 비단조성은 해소됐지만 대가가 크다

tau_c 스윕 (300도 기준)

| tau_c [s] | GPC 온도 기울기 | 문헌 1 시그마 안 | 300도 퍼지 OH 손실 | H2O 곡선 단조 |
|---|---|---|---|---|
| 1 | -0.01645 | 아니오 | 94.8 % | 예 |
| 3 | -0.01293 | 아니오 | 85.9 % | 예 |
| **10** | **-0.00718** | **예** | **64.7 %** | 예 |
| 30 | -0.00200 | 아니오 | 37.9 % | 예 |
| 100 | +0.00103 | 아니오 | 16.5 % | 예 |
| 1000 | +0.00054 | 아니오 | 17.9 % | 예 |

**비단조성은 전 구간에서 해소된다.** 목적은 달성했다.

문제는 세 가지다.

1. **문헌 기울기를 맞추는 tau_c가 10 s 한 점뿐이다.** 미지 파라미터를 결과에 맞춰 고정하는 것이므로 사실상 피팅이다. 이 프로젝트가 지켜온 "모델에 넣지 않은 관계를 재현하는지로 검증한다"는 원칙과 정면으로 충돌한다.

2. **그 조건에서 300도 퍼지 1초에 OH의 65 %를 잃는다.** 검증할 근거가 없는 큰 주장이다. 사실이라면 GPC가 퍼지 시간에 강하게 의존해야 하는데, 그런 보고를 문헌에서 찾지 못했다.

3. **결과가 tau_c에 35.7 % 의존한다** (tau_c 0.3 ~ 30 s 구간). 기존 모델의 미지 파라미터 r_diss는 의존도가 0.02 %였다(Phase 2 3절).

tau_c가 커지면 기울기가 양수로 뒤집히는 것도 짚어둘 만하다. 상세 균형 때문에 응축을 늦추면 해리도 같이 느려지고, 그러면 H2O 반쪽이 sigma_OH0에 도달하지 못해 온도 의존 자체가 사라진다.

## A.4 판단: 되돌린다

**문서화된 구조적 한계를 미검증 피팅 파라미터와 맞바꾸는 것은 손해다.**

| | flux_coupled (채택) | arrhenius |
|---|---|---|
| 미지 파라미터 | r_diss 1개 | r_diss + tau_c |
| 결과 의존도 | 0.02 % | 35.7 % |
| 파라미터 결정 방식 | 임의값으로 두고 둔감성 확인 | 문헌 기울기에 맞춰 고정 (피팅) |
| H2O 곡선 | 0.77 % 비단조 봉우리 | 단조 |
| 퍼지 OH 손실 | 0 (구조상) | 65 % (미검증) |
| GPC 온도 기울기 | -0.00668, 문헌 1 시그마 안 | tau_c = 10에서만 안에 듦 |

비단조 봉우리는 마진 약 5.7에서 나타나고 운전점은 마진 42다. Phase 5의 필요 마진 역산에 영향이 없음을 이미 확인했다.

`CONDENSATION_MODEL = "flux_coupled"`를 기본으로 유지하고 `"arrhenius"`는 비교용으로 코드에 남겼다. 퍼지 단계와 `rhs_purge`도 남겼다. 나중에 퍼지 시간 의존 데이터나 탈수산화 전인자를 확보하면 스위치만 바꾸면 된다.
