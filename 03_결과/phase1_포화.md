## 2. 모델 구조를 설계에서 바꿨다

`01_모델설계.md` 3.2절의 원래 식은 σ_Me를 "흡착된 Al(CH3)x 면밀도" 하나로 뒀다. 이 상태로는 두 가지를 재현할 수 없다.

- 입체 차폐를 만드는 것은 **메틸기**인데, Me/Al 비가 1.5에서 3까지 변한다 [P05] Fig.22c
- 그 결과 Al 밀도와 메틸 밀도가 비례하지 않는다

그래서 [P05] 4절의 서술 그대로 두 과정으로 분리하고 Al과 Me를 따로 추적했다.

    흡착        TMA -> 표면.  Al +1, Me +3.   rate = beta_ads x Gamma x theta_free
    리간드교환   Me* + OH* -> CH4(g).  Me -1, OH -1.   rate = k_ex x s_Me x s_OH

    theta_free = 1 - a_Me x s_Me        (메틸기가 만드는 차폐)

**이 구조가 만드는 물리**: OH가 많으면 메틸이 빨리 제거되고, 그만큼 면적이 열려 Al이 더 붙는다. [P05] Eq.24의 인과가 모델 안에서 자동으로 생긴다. Eq.24를 입력하지 않고도 재현된다는 뜻이고, 이것이 4절 B-1 검증의 근거다.

**포화 시 성립하는 관계**

    OH 고갈   -> 교환 정지
    s_Me -> 1/a_Me -> theta_free -> 0 -> 흡착 정지
    질량수지   3 s_Al = s_Me + (소모된 OH)          [P05] Eq.23과 동일

## 3. 미지 파라미터 k_ex 처리

리간드교환 속도상수 k_ex는 문헌에 절대값이 없다. [P05]는 "리간드교환이 흡착보다 먼저 완료된다"는 정성 서술만 준다.

무차원비로 두고 결과가 그 값에 둔감함을 확인했다.

    Da_ex = (k_ex x sMe_max x s_OH0) / (beta x Gamma)

| Da_ex | 포화 Al 밀도 상대산포 |
|---|---|
| 10, 100, 1000, 10000 | Da_ex >= 100 구간에서 1.45e-5 |

Da_ex >= 100이면 포화값이 수렴한다. [P05]의 서술 조건이 바로 이 구간이다. **미지 파라미터가 결론을 바꾸지 않는다.**

## 4. 검증 결과

### 4.1 1단계: 코드 자체 (01번 9.1절)

| 항목 | 결과 | 기준 | 판정 |
|---|---|---|---|
| 해석해 대조 (입체 포화, k_ex = 0) | 6.51e-12 | 1e-4 | 통과 |
| 해석해 대조 (OH 고갈, s_Me 고정) | 2.37e-11 | 1e-4 | 통과 |
| 적분 수렴 (rtol 1e-8 vs 1e-12) | 5.76e-12 | 1e-3 | 통과 |
| 물리적 범위 (음수/1 초과 없음) | 1.81e-27 | 1e-9 | 통과 |
| 질량수지 3 s_Al = s_Me + dOH | 4.10e-15 | 1e-8 | 통과 |
| 포화값의 k_ex 둔감성 | 1.45e-5 | 1e-2 | 통과 |

해석해는 두 극한에서 각각 확인했다.

    입체 포화 (k_ex = 0)   s_Me(t) = sMe_max [1 - exp(-t/tau)],  tau = 1/(3 a_Me beta Gamma)
    OH 고갈 (s_Me 고정)     s_OH(t) = s_OH0 exp(-t/tau),          tau = 1/(k_ex s_Me)

첫 번째 식은 Phase 5가 가정하는 지수형 포화 `GPC(D) = GPC_sat[1 - exp(-D/D0)]`의 근거이기도 하다.

### 4.3 2단계-B: 예측 검증 (모델에 넣지 않은 관계 재현)

**B-1. [P05] Eq.24 재현**

c_OH를 0에서 9 nm^-2까지 스윕하며 포화 Al 밀도를 회귀했다.

    모델    dc_Al = 1.833 + 0.3333 c_OH
    문헌    dc_Al = 1.680 + 0.3700 c_OH        [P05] Eq.24

절편 차이 9.1 %, 기울기 차이 9.9 %.

기울기에 대해 짚어둘 것이 있다. 모델은 화학량론에서 **정확히 1/3**을 낸다(TMA 한 분자의 메틸 3개). [P05] 본문도 1/0.37 = 2.7을 "almost three"로 해석하며 3을 기대한다고 쓴다. 즉 0.3333이 기구적으로 맞는 값이고 문헌 0.37은 산점 피팅의 편차로 보는 것이 타당하다.

**B-2. Me/Al 비의 c_OH 의존**

| c_OH [nm^-2] | 모델 Me/Al | 문헌 Me/Al |
|---|---|---|
| 0 | 3.00 | 3.0 |
| 3 | 1.94 | 2.0 |
| 6 | 1.43 | 1.5 |

문헌은 [P05] Fig.23. 세 점 모두 3 % 이내.

**B-3. [P05] Fig.20 온도 독립성**

c_OH를 2.0 nm^-2로 고정하고 온도만 80에서 300도로 바꿨다.

    모델 기울기   -0.000000 nm^-2 / 도
    문헌 기울기   -0.000300 +/- 0.000500 nm^-2 / 도

통과. 이것은 `01_모델설계.md` 4.2절 주장("GPC 감소는 OH 밀도 단독이 원인")의 직접 테스트다.

주의: Gamma가 1/sqrt(T)로 변하므로 포화 **속도**는 온도에 따라 변한다. 변하지 않아야 하는 것은 포화 **값**이다. 모델이 이 구분을 지킨다.

**B-4. 역방향 검증: Eq.24 절편이 함의하는 sMe_max**

모델은 절편 = sMe_max / 3을 예측한다. 문헌 절편 1.68을 역산하면

    sMe_max = 1.68 x 3 = 5.04 nm^-2

[P05] Fig.22b의 실측 포화 메틸 밀도 5 ~ 6 nm^-2 안에 들어간다. 통과.

이것은 파라미터 #4에 대한 독립 확인이다. 서로 다른 두 문헌 관측(Eq.24 절편, Fig.22b 직접 측정)이 같은 값을 가리킨다.

**sMe_max 감도** (02번 #4의 불확실 구간)

| sMe_max [nm^-2] | Eq.24 절편 | Eq.24 기울기 | GPC @ 220도 |
|---|---|---|---|
| 5.0 | 1.667 | 0.3333 | 1.096 |
| 5.5 (기본값) | 1.833 | 0.3333 | 1.137 |
| 6.0 | 2.000 | 0.3333 | 1.177 |
| 7.2 (이론 상한) | 2.400 | 0.3333 | 1.274 |

기울기는 sMe_max와 무관하다(화학량론이 정한다). 절편과 GPC 절대값만 움직인다.

## 5. 주 결과

### 5.1 포화 곡선

`fig/phase1_saturation_curve.png`

| T [도] | D0 [mTorr s] | GPC_sat [Å/cyc] | 지수형 근사 RMS 잔차 | 포화 시간 [ms] |
|---|---|---|---|---|
| 150 | 1.7 | 1.250 | 0.0466 | 17.35 |
| 200 | 1.7 | 1.169 | 0.0426 | 17.21 |
| 250 | 1.7 | 1.088 | 0.0383 | 16.93 |
| 300 | 1.7 | 1.008 | 0.0337 | 16.50 |

조건: P_TMA = 0.1 Torr, beta_TMA = 1.0e-3.

**D0가 온도에 거의 무관하다.** 포화 속도는 흡착(입체 채움)이 정하고, 그것은 beta와 Gamma가 지배하는데 Gamma의 온도 의존이 1/sqrt(T)로 약하기 때문이다. 온도에 따라 변하는 것은 도달하는 높이(GPC_sat)지 도달 속도가 아니다.

**dose 비교 기준** (02번 #10 수정 사항)

    모델 D0             1.7 mTorr s  (포화 시간 약 17 ms)
    통상 TMA 펄스        15 ~ 100 ms  = 1.5 ~ 10 mTorr s @ 0.1 Torr
    [A19] LHAR dose      190 ~ 1200 mTorr s

[A19]의 값은 종횡비 10000짜리 구조를 채우는 dose다. 확산 제한이 지배하므로 평판 표면과 직접 비교하면 안 된다. 평판 기준으로 보면 모델 D0는 통상 펄스 범위 안이다.

### 5.2 포화를 거는 원인

`01_모델설계.md` 3.2절이 Phase 1의 결과로 남겨둔 물음이다.

| T [도] | 포화 시 OH 잔량 | 메틸 충전율 | 판정 |
|---|---|---|---|
| 150 | 0.0 % | 100.0 % | 입체 장애 |
| 200 | 0.0 % | 100.0 % | 입체 장애 |
| 250 | 0.0 % | 100.0 % | 입체 장애 |
| 300 | 0.0 % | 100.0 % | 입체 장애 |

**전 온도에서 입체 장애가 포화를 건다.** OH는 전부 소모되지만 그것이 정지 원인은 아니다. OH가 다 소모된 뒤에도 흡착은 계속되고(해리 경로), 메틸이 면적을 다 채운 시점에서 멈춘다.

`01_모델설계.md` 1절 가정 2가 계산으로 확인됐다.

## 6. 한계와 이월 사항

**6.1 GPC가 체계적으로 2~8 % 높다**

원인은 sMe_max = 5.5 nm^-2를 쓴 것이다(실측 5~6의 중간값). B-4가 함의하는 5.04를 쓰면 GPC @ 220도가 1.096으로 Puurunen 피팅 1.087에 거의 붙는다.

기본값을 5.5로 유지한 이유: 문헌 관측 범위의 중간값이라는 독립 근거가 있고, 5.04로 바꾸는 것은 결과에 맞추는 캘리브레이션이 되기 때문이다. 4.3절 감도표로 영향 범위를 명시하는 쪽을 택했다.

**6.2 Phase 5의 지수형 가정이 정확하지 않다**

포화 곡선을 `GPC_sat[1 - exp(-D/D0)]`로 근사하면 RMS 잔차가 3.4 ~ 4.7 % 남는다. `01_모델설계.md` 6-2절 "주의"에 적어둔 우려가 확인됐다.

이유는 흡착 속도가 `1 - a_Me s_Me`에 비례하는 동시에 리간드교환이 s_Me를 깎아 자리를 되돌려주기 때문이다. 두 과정이 겹쳐 단일 지수가 되지 않는다.

**Phase 5는 이 실제 곡선으로 다시 계산한다.** 지수형 표(01번 6-2절)는 폐기하지 않되 근사임을 명시한다.

**6.3 온도 기울기가 문헌보다 약하다**

    모델 -0.00666 vs 문헌 -0.00820 nm^-2 / 도

1 시그마 안이므로 통과지만, Phase 3의 민감도 S(T)에 직접 영향을 준다.

    문헌 기준 S(200도) = 0.176 %/K
    모델 기준 S(200도) = 0.00666 / 4.83 = 0.138 %/K

Phase 3에서 두 값을 모두 제시하고 차이를 명시한다.

**6.4 검증할 수 없는 것** (01번 9.3절)

- soft-saturation: [A19]가 H2O 반쪽에서 관측한 비Langmuir 거동. 우리 모델은 Langmuir 형이라 재현 불가
- 실측 포화 곡선 원데이터 없음. 곡선 형태는 예측으로 남는다
